# 외부 인터페이스

이 시스템은 외부 API를 제공하지 않는다. 사람이 다루는 외부 형식은 엑셀 파일뿐이며, 모두 자산담당자 전용 화면 `/asset/excel/main.do`에서 오간다.

## 공통 규칙

- 업로드: `.xlsx`(`.xls`도 읽음), 첫 시트만 읽는다.
  - 1행은 머리글이며 내용을 검사하지 않고 건너뛴다. 2행부터 데이터다.
  - 빈 행은 위치와 관계없이 무시한다.
  - 엑셀이 아닌 파일·빈 파일은 "파일" 오류로 거부한다.
  - 업로드 크기와 확장자 제한은 공통컴포넌트 설정(`Globals.fileUpload.*`)을 따른다.
- 결과: 전부 성공하거나 전부 실패한다.
  - 성공하면 저장 건수를 보여 준다.
  - 실패하면 저장은 0건이고 `행 번호(엑셀 실제 행) · 이유` 목록을 보여 준다.
  - 모든 행을 먼저 검사하므로 한 번에 모든 오류가 나온다.
  - 저장 중 경쟁 상황(다른 사람이 같은 이름을 먼저 저장 등)으로 실패하면 행 목록 대신 한 줄 메시지가 나오며 역시 0건 저장이다.
- 내려받기: `.xlsx`, 1행 머리글(아래 열 이름 그대로), 파일 이름은 한글이다: `재고현황_yyyyMMdd.xlsx`, `자산대장_yyyyMMdd.xlsx`(내려받는 날의 Asia/Seoul 날짜), `신청내역_<시작일>-<종료일>.xlsx`(yyyyMMdd). 빈 업로드 양식도 내려받을 수 있다(`품목_일괄등록_양식.xlsx`, `자산_일괄등록_양식.xlsx`).
  - 헤더는 `Content-Disposition: attachment; filename="<영문 대체 이름>"; filename*=UTF-8''<한글 이름 퍼센트 인코딩>`이다. 영문 대체 이름은 `stock_status_yyyyMMdd.xlsx`, `asset_ledger_yyyyMMdd.xlsx`, `requests_<시작일>-<종료일>.xlsx`, `item_upload_template.xlsx`, `asset_upload_template.xlsx`.

## 품목 일괄등록(업로드)

| 열 | 이름 | 필수 | 허용 값 | 오류 |
|---|---|---|---|---|
| A | 품목명 | 예 | 100자 이내 | 누락, 사용 중 품목과 이름 중복, 파일 안 이름 중복(대소문자 무시) |
| B | 유형 | 예 | `수량`/`수량 비품` 또는 `개별`/`개별 자산` | 누락, 그 밖의 값 |
| C | 분류코드 | 아니요 | 공통코드 AST001의 사용 중 코드(`OFFICE`, `SUPPLY`, `IT`, `FURNITURE` …) | 없는 코드, 사용 안 하는 코드 |
| D | 단위코드 | 아니요 | 공통코드 AST002의 사용 중 코드(`EA`, `BOX`, `PACK`, `SET` …) | 없는 코드, 사용 안 하는 코드 |
| E | 최소 수량 | 아니요(빈칸=0) | 0 이상 정수 | 음수, 숫자 아님 |

결과: 품목코드는 시스템이 만든다. 재고·확보 수량 0, 사용 중 상태로 저장된다.

## 자산 일괄등록(업로드)

| 열 | 이름 | 필수 | 허용 값 | 오류 |
|---|---|---|---|---|
| A | 품목코드 | 예 | 사용 중인 개별 자산 유형 품목의 코드 | 누락, 없는 품목, 수량 비품 품목, 사용 중지 품목 |
| B | 자산번호 | 예 | 50자 이내 | 누락, 이미 있는 번호(폐기 자산 포함), 파일 안 중복 |
| C | 비고 | 아니요 | 500자 이내 | — |

결과: 한 행 = 입고 1건. 자산은 보관 상태로 만들어지고 자산 이력 첫 행과 재고 이력 `IN` +1이 남는다.

## 재고 현황(내려받기)

열: 품목코드, 품목명, 유형, 분류, 단위, 재고 또는 보관 수, 확보 수량, 가용, 최소 수량, 사용 여부.
- 유형·분류·단위·사용 여부는 한글 이름으로 나온다.
- 재고 또는 보관 수: 수량 비품은 재고 수량, 개별 자산은 보관 자산 수.
- 가용: 수량 비품은 재고, 개별 자산은 보관 수 − 확보 수량.
- 사용 중지 품목도 포함한다.

## 자산 대장(내려받기)

열: 자산번호, 품목, 상태(보관/사용/수리/폐기), 현재 사용자(이름), 비고. 폐기 자산도 포함한다.

## 신청 내역(내려받기)

- 입력: 시작일·종료일(`yyyy-MM-dd`, 신청일 기준, 양 끝 포함). 날짜 형식이 틀리면 화면에 오류를 보여 주고 파일을 만들지 않는다.
- 열: 신청번호, 신청일, 신청자, 부서, 품목, 신청 수량, 승인 수량, 품목 결과(미결/승인/반려), 헤더 상태(대기/반려/승인/지급완료/신청취소/지급취소), 승인자, 처리일.
- 한 행 = 신청 품목 한 줄. 정렬은 신청일, 신청번호, 품목코드 순이다.
- 부서는 신청 당시 부서다. 승인자는 승인·반려를 처리한 사람이다.
