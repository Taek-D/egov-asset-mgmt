# 0006. 야간 집계는 앱 내부 스케줄러 + 배치 결과만 공유

## 배경
매일 밤 집계하고, 성공·실패를 공통컴포넌트 배치 결과 화면에서 확인할 수 있어야 한다. 공통컴포넌트 배치 관리는 스케줄 행마다 Quartz 잡을 만들고, 작업에 등록된 프로그램을 셸 명령으로 실행한다.

## 결정
- 집계는 앱 내부 Spring 스케줄러(`context-asset-scheduling.xml`, 기본 cron `0 0 2 * * *`, Asia/Seoul)가 서비스 메서드를 직접 호출한다.
- 공통컴포넌트와는 배치 작업 행 1건(고정 ID)만 등록하고, 실행마다 배치 결과 행을 직접 쓴다. 결과 행의 스케줄 ID 칸에는 스케줄 행이 없는 고정값을 넣는다.
- 배치 스케줄 행은 만들지 않는다.

## 대안
- **공통컴포넌트 배치 스케줄 사용**: 작업을 셸 스크립트로 만들어야 하고, 셸이 앱 트랜잭션·서비스 규칙(가용 정의)을 공유하지 못한다. 컨테이너에 셸 스크립트와 권한도 필요하다.
- **Spring Batch 잡으로 구성**: 단일 쿼리 집계에 비해 과하다.

## 결과
- 배치 결과 화면에 집계 실행이 보인다. 공통컴포넌트 배치 작업 화면에서 그 작업 행을 지우거나 스케줄을 붙이는 것은 이 결정만으로는 막지 못해, 2차에서 배치 화면을 보기 전용으로 잠갔다(`60_asset_batch_lock.sql`).
- 집계 시각은 공통컴포넌트 화면이 아니라 설정(플레이스홀더)으로 바꾼다.
- 여러 앱 인스턴스를 띄우면 인스턴스마다 집계가 돈다(단일 서버 전제).
