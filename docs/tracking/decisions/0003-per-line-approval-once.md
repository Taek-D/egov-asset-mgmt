# 0003. 품목별 승인을 한 화면에서 한 번에, 전부 또는 전무

## 배경
신청서 한 장에 여러 품목이 들어간다. 승인자가 품목마다 다르게 판단하고 싶을 수 있고(수량 축소, 일부 반려), 재고가 모자란 품목이 섞일 수 있다.

## 결정
- 승인자는 한 화면에서 모든 품목의 처리를 정한다: 승인 수량(1~신청 수량) 또는 반려+사유.
- 처리는 한 번에 제출하며, 미결 품목이 있으면 제출할 수 없다.
- 승인 품목 중 하나라도 가용이 모자라면 아무것도 바꾸지 않고 모자란 품목 전부를 알린다.

## 대안
- **신청서 통째 승인/반려**: 처음 안이었으나, 일부 품목만 조정하려면 반려 후 재신청해야 해서 사용자가 품목별을 택했다.
- **품목별로 여러 번 나눠 승인**: 신청서가 부분 승인 상태로 오래 남고 상태 전이가 복잡해진다. 사용자가 거절했다.
- **가능한 품목만 부분 반영**: 전부 또는 전무 원칙에 어긋난다.

## 결과
- 신청서 헤더 상태는 대기 → 승인/반려 한 번으로 끝난다(부분 승인 상태 없음).
- 승인 한 번이 여러 품목의 잠금과 확보를 한 트랜잭션에서 처리한다. 가용 확인을 모든 품목에 먼저 하고 그다음 바꾼다.
- 반려 사유는 품목 단위로 남는다. 헤더 처리 이력의 사유는 비어 있다.
